# Angry Judge: The Short Rant Contest

Entry for the make.fun bounty [Angry Judge: The Short Rant Contest](https://make.fun/bounty/u-riidzhsn-angry-judge-the-short-rant-contest-b9f46046).

`main.ts` (Node 22, standard library only) writes one short rant about a small everyday annoyance to `entry.txt`: the passenger who stands up in the aisle the second the plane lands, going nowhere, in a hurry to be first in line to stand still.

Run it with `MAKEFUN_OUTPUT_DIR` set to the output directory, or it defaults to `/output`.
